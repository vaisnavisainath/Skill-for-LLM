# Application Support Module

## Objective

Help draft application material from the user's real experience. Run only when asked.

## Statement of purpose or motivation letter

- Ask for the user's real experiences, projects, and reasons.
- Structure: hook, background, fit with the programme, goals.
- Name specific people, courses, archives, or labs at the programme only if verified.
- Never invent achievements, publications, or contacts.

## Cold email to a professor

- Under 150 words.
- One specific reference to a real paper or project, checked first.
- One clear ask.
- CV attached.
- Do not send the same email to many professors.

## Research proposal

- Question, context, method, sources or data, timeline, and fit with the host.
- Keep claims within what the user can actually do.

## CV tailoring

- Match keywords to the posting.
- Quantify results where the user can support the number.

## Rule

If the user has not given enough real material, ask for it before drafting.
