# Ranking Module

## Objective

Score the survivors and sort them so the user can act in the right order.

## Criteria

Score each from 1 to 5 and show the reasoning in a few words.

| Criterion | What to check |
|---|---|
| Profile fit | Field, framework, region, period, languages, methods against the programme's strengths |
| Funding adequacy | Tuition, stipend, travel, insurance |
| Career and research value | Supervisor or host fit, network, outputs, link to the user's goal |
| Competitiveness | Reach, target, or safe, given the user's record |
| Effort and time left | Documents needed against days before the deadline |

## Competitiveness labels

- Reach: the user's record is below the usual profile of selected candidates
- Target: the record is in line with it
- Safe: the record is above it, or the pool is small and well matched

These are qualitative. Never give a percentage chance and never promise selection.

## Humanities and social science fit check

Match the user's theoretical framework, region, period, and languages against each programme's strengths, not its general ranking. For PhDs, shortlist supervisors whose recent work matches the user's before any email is drafted.

## Switch behaviour

If balanced_mix is ON: aim for a spread of reach, target, and safe options. Say so if the list is lopsided and why.

## Output

Top 5 to 10, sorted by deadline first, then by total score.
