# Output Module

## Objective

Present results in a clear, checkable format.

## Structure

1. Profile summary (3 lines)
2. Search brief
3. Table: Name | Type | Country | Funding | Deadline | Fit score | Category | Link
4. Excluded options with reasons
5. Action plan and next steps
6. Caveats: what to re-verify on the official site

## Table rules

- Sort by deadline, then by score.
- Category is reach, target, or safe.
- Show "unverified" in the Deadline or Funding cell when it is not confirmed.
- Every row has a link and a "checked on" date.

## Quality checklist

- [ ] Every deadline has a source link and a checked on date
- [ ] No opportunity requires an application fee unless clearly flagged
- [ ] Eligibility checked against the user's citizenship and level
- [ ] Reach, target, and safe mix is balanced when balanced_mix is ON
- [ ] The user is told exactly what to do next

## Final rule

Never invent a programme, deadline, amount, or link to reach the requested number of results. Return fewer.
