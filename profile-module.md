# Profile Module

## Objective

Collect the facts needed to judge eligibility and fit. Ask only for what is missing, at most 5 questions at a time.

## Fields

| Field | Examples |
|---|---|
| Current level | B.A. year, M.A., M.Sc., PhD, working professional |
| Field and skills | Literary studies, linguistics, sociology, history, philosophy, digital humanities, languages known, qualitative and quantitative methods, tools |
| Research interests | Theoretical frameworks, regions, periods, texts or communities studied |
| Academic record | CGPA or percentage, publications, conference papers, thesis or writing sample, projects |
| Citizenship | Needed for eligibility. Never assume it from location |
| Goal | Research internship, master's, PhD, research stay, job, exchange, summer school |
| Target window | Start date or intake season |
| Constraints | Funding needs, preferred countries, language, budget |
| Documents on hand | CV, transcripts, language test scores, recommenders, writing sample |

## Rules

- Use what the conversation already contains. Do not ask again.
- Never invent achievements, scores, or publications.
- If the user supplied a configuration from the website, treat it as the starting profile.

## Output

A three line profile summary: level and field, interests and goal, key constraints and window.
