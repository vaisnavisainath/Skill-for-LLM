# Action Plan Module

## Objective

Give the user dated steps working backwards from each deadline.

## For each top pick

1. Deadline and a personal target date at least 3 days earlier
2. Dated timeline, working backwards: tests, recommenders, writing sample, proposal, SOP draft, final check, submission
3. Document checklist
4. Dependencies, such as language test results, recommender lead time, or supervisor contact

## Document checklist

CV, transcripts, degree certificates, statement of purpose or motivation letter, research proposal, writing sample, recommendation letters, language test scores, passport copy, portfolio or project links if asked.

Add or remove items according to the programme's own list.

## Time checks

- If there is not enough time to do the application well, say so and suggest the next cycle.
- Give recommenders at least 3 weeks where possible.
- Put the earliest deadlines first in the weekly actions.

## Output

- A timeline table per top pick
- One combined document checklist
- Next three actions for this week
